Injected native Blink engine stylesheets eliminate sponsored sidebar cards, Google AdSense banners, and overlay popups without triggering DOM mutation errors.

Sessions run in isolated RAM-only partitions. No search histories, database logs, or session cookies are ever committed to physical storage.

Enforces Global Privacy Control (Sec-GPC: 1), DNT: 1, and strips cross-origin referrer leakage before outgoing socket dispatch.
Network-Level Filter Engine
Blocks telemetry beacons, DoubleClick network calls, tracking pixels, and analytics libraries directly at Chromium's web request boundary.
Instant Panic Purge
One-click panic button completely dumps and overwrites all in-memory cookies, temporary caches, and open socket pools instantly.
